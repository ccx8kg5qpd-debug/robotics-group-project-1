# 数据集说明

最终数据集共 1000 张图片和 1000 个 YOLO 标注文件：

| 划分 | 图片 | 标注 | 自采 | COCO 2017 |
|---|---:|---:|---:|---:|
| train | 800 | 800 | 20 | 780 |
| val | 100 | 100 | 5 | 95 |
| test | 100 | 100 | 5 | 95 |
| 合计 | 1000 | 1000 | 30 | 970 |

类别映射：`0=bottle`、`1=mouse`。

仓库保留以下可审计材料：

- `data.yaml`：YOLO 数据配置
- `split_report.txt`：划分与类别统计
- `split_manifest.tsv`：1000 张图片的划分和来源类型
- `DATASET_VALIDATION.md`：图片/标注对应和标签格式核验结果
- `source_info/`：970 张外部图片的来源、许可和 SHA-256 清单

完整图片和标签随课程最终提交 ZIP 提交，不在公共 GitHub 仓库中重复发布。
